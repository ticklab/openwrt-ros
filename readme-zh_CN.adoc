== ROS2 发行版源码构建

各发行版目录（`ros2-humble`、`ros2-jazzy`、`ros2-lyrical`）提供对应 ROS 2 发行版的源码构建包，
参考官方 Ubuntu-Development-Setup 流程：使用 `vcs` 导入 `ros2.repos`
拉取工作区，再用 `colcon` 结合 OpenWrt 工具链交叉编译，
安装到目标根文件系统的 `/opt/ros/<发行版>`。

[cols="1,2,3"]
|===
| 软件包 | 发行版 | 说明

| ros2-humble | Humble Hawksbill | 基于 ros2/ros2 humble 分支源码构建
| ros2-jazzy | Jazzy Jalisco | 基于 ros2/ros2 jazzy 分支源码构建
| ros2-lyrical | Lyrical | 基于 ros2/ros2 lyrical 分支源码构建
|===

各发行版拆分为核心运行时包与独立的 demo 包：

[cols="1,2,3"]
|===
| 核心包 | demo 包 | 说明

| ros2-humble | ros2-humble-demo | 来自 ros2/demos 的示例/教程节点
| ros2-jazzy | ros2-jazzy-demo | 来自 ros2/demos 的示例/教程节点
| ros2-lyrical | ros2-lyrical-demo | 来自 ros2/demos 的示例/教程节点
|===

说明：

* 源码固定到对应分支的提交，`PKG_MIRROR_HASH` 由 OpenWrt 下载流程生成校验。
* `Build/Prepare` 将工作区放在 `PKG_BUILD_DIR` 之外，并执行
  `vcs import --retry 5 --skip-existing`，避免临时网络故障破坏工作区。
* `Build/Configure` 依据 `files/openwrt-toolchain.cmake.in` 生成 CMake
  交叉编译工具链文件。
* `Build/Compile` 调用 `colcon build --executor sequential --merge-install`
  并传入工具链文件，顺序执行以确保依赖包先完成安装。
* 生成的 `.ipk` 仅安装 `/opt/ros/<发行版>` 下的运行时部分（不含头文件、
  源码与 CMake 包配置），并附带 `files/setup.sh`，按目标路径
  `/opt/ros/<发行版>` 配置环境。
* 两个包由同一次 colcon 构建产出。`ros2/demos` 下各 demo 包的安装文件
  清单取自 colcon 的 install manifest，被迁入独立的 `<发行版>-demo`
  `.ipk`，因此核心运行时可以不含 demo/教程节点单独安装。demo 包依赖
  核心包。

=== DDS 中间件选择

各发行版同时构建 Fast DDS（`rmw_fastrtps_cpp`）与 Cyclone DDS
（`rmw_cyclonedds_cpp`）两种中间件实现。在 menuconfig 的
"DDS middleware" -> "Default DDS middleware" 菜单中选择默认实现，
该选择通过 `RMW_IMPLEMENTATION` CMake 选项传入。默认使用 Fast DDS。
此选择仅设置默认值，运行时仍可通过 `RMW_IMPLEMENTATION`
环境变量覆盖。

== 系统库

`libs/` 目录提供默认 OpenWrt feeds 中缺失、或需要特定版本的第三方
C/C++ 库。

[cols="1,1,3"]
|===
| 软件包 | 版本 | 说明

| asio | 1.22.1 | 仅头文件的 C++ 网络库（Fast DDS）。固定该版本以保留
  Humble 的 Fast DDS 2.6.x 所需的已废弃 `asio::io_service` 接口
| console_bridge | 1.0.2 | 简单 C++ 日志抽象库，`console_bridge_vendor` /
  rosconsole_bridge 依赖
| cpptoml | 0.1.1 | 仅头文件的 TOML 解析库，iceoryx 依赖
| eigen | 3.4.0 | 仅头文件的 C++ 线性代数库
| foonathan-memory | 0.7.4 | Fast DDS 使用的自定义内存分配器
  （`foonathan_memory_vendor`）
| orocos-kdl | 1.5.1 | Orocos 运动学与动力学库
| pybind11 | 2.11.1 | C++/Python 互操作
| spdlog | 1.12.0 | 快速 C++ 日志库
| tinyxml2 | 10.0.0 | 小型 C++ XML 解析库
| yaml-cpp | 0.8.0 | `yaml_cpp_vendor` 所需的 YAML 解析/生成库
  （>= 0.8.0）
|===

上游 ROS 的 `*_vendor` 包会在构建时从网络下载第三方依赖。将这些库作为
OpenWrt 软件包提供后，ROS 2 构建即为封闭且可复现的：vendor 包会检测到
系统安装并跳过下载步骤。
